BlueLab Audio Plugins

Réduire les bruits de glissement des doigts

Mon ami le développeur français Nicolas Dittlo, a développé un plugin particulièrement efficace pour réduire les bruits de frottement de la main gauche ( pour les droitiers ) sur les cordes de la guitare.

Les bruits de glissement des doigts sur les cordes peuvent rapidement devenir gênants. Ils font naturellement partie du jeu de la guitare, mais lorsqu'ils sont trop présents ils attirent l'attention de l'auditeur et masquent parfois les nuances de l'interprétation.

Grâce à une analyse intelligente du signal audio, le plugin atténue les bruits de glissement tout en conservant le caractère naturel de la guitare. Contrairement à un simple égaliseur, le traitement cible principalement les parasites sans altérer le timbre de l'instrument.

Idéal pour

  • Les enregistrements de guitare classique.
  • La guitare acoustique et folk.
  • Le home studio.
  • Le nettoyage d'anciens enregistrements.
Pour tous les guitaristes qui enregistrent leur instrument, c'est un outil que je recommande sans hésitation.
